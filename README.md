## Featured Projects

### [FPGA Breakout Game](https://github.com/chengmiao2005/FPGA-Breakout-Game)
**Verilog HDL · RTL Design · Finite-State Machines · VGA · Xilinx Vivado**

A modular Breakout-style digital system with separate control, ball-motion, collision, display, and VGA-timing logic, together with a simulation-oriented development-board wrapper.

### [LPC Voice Changer in MATLAB](https://github.com/chengmiao2005/LPC-Voice-Changer-MATLAB)
**MATLAB · Digital Signal Processing · LPC · Speech Analysis/Synthesis**

A frame-based speech-processing project using LPC analysis, autocorrelation-based pitch-period estimation, modified excitation, and speech resynthesis.

### [Wireless Power Transfer Modeling](https://github.com/chengmiao2005/Wireless-Power-Transfer-MATLAB)
**MATLAB · Circuit Modeling · Complex Impedance · Parameter Sweeps**

A steady-state coupled-coil wireless-power model for compensation-parameter calculation, branch-current analysis, power/efficiency evaluation, and frequency/coupling studies.
